## The code change (PR #35)
- **What it adds:** the `terraform-plan` job in `.github/workflows/ci.yml` sets `TF_VAR_member_instance: ${{ vars.TF_MEMBER_INSTANCE || 'false' }}`.
- **Why a variable:** the stack's instance guard (`infra/bootstrap/guard.tf`) refuses a plan unless `member_instance` matches the account. With a variable that defaults to `'false'`, the code could merge first without changing CI's behaviour, and the setting then flips together with the role and bucket.
- **Merged** at the approved head `d27f134`, giving `main` `f6a924b` (18:21:47Z). All seven checks passed on the PR and on `main`.
- **Before the switch,** CI still planned the management instance: the gate counted 8 resources.
