# 23. M5: the Glue backfill, the parity test, and Redshift on demand

Date: 2026-10-10 · Status: **accepted** for M5a (the code in this PR). The two stacks below are designed here and built, one reviewed PR each, in M5b and M5c. Builds on [ADR-0007](0007-polars-daily-spark-history.md), [ADR-0004](0004-network-profiles.md), [ADR-0011](0011-third-party-data-rights.md) and [ADR-0018](0018-workload-permissions-boundary.md).

## Context
PLAN.md M5: a PySpark job on Glue reproduces the seasonal-shape parameters the Polars reference produces, and a Redshift Serverless workgroup loads and queries the curve and price history. The draft is done when the Glue backfill and a Redshift query have each run once. Only synthetic data reaches AWS (ADR-0011).

## Decision
### Data and code (M5a, this PR)
- **The history is generated, not uploaded.** `energy_curves.synthetic_prices` is the deterministic, seeded price function (moved out of `ingestion/synthetic.py`, which imports it back; a digest test pinned its output before the move). The Glue job calls it inside Spark, one task per slice of days, so no object is uploaded and nothing real can reach the job. The catalog has 6 series; 1983-01-03 to 2024-04-05 is 10,765 business days, about 64,600 rows. The shape estimate reads 5 series in the 2014 to 2024-04-05 window, about 13,000 rows. Spark is far more than the volume needs (ADR-0007 already says so).
- **One contract, two engines.** `energy_curves.curves.shape_core` holds the constants, `quantize_s`, `ShapeEstimationError` and the canonical parameter text; both `curves/shape.py` (Polars) and `jobs/glue/shape_job.py` (PySpark) use it. The job imports only PySpark, the standard library, `catalog`, `synthetic_prices` and `shape_core`; an AST test enforces this (no Polars, no HTTP client).
- **The parity test** runs in the existing `glue-compat` job (Python 3.11, Java 17, PySpark 3.5.6) on a one-year slice and on the full history, on a history generated in Spark and one generated in Python. It requires identical keys and `n_obs`, `s` within 1e-9, and, as the stronger check, identical canonical text and SHA-256 (a rounding-boundary flip is reported, not hidden). It also checks the exclusions (the negative-price day, a non-positive future), the error messages for a thin or missing group, a window that cuts a month, and byte-identical output across runs and partition counts. The 13 Spark cases take about 25 seconds, so CI runs the full history; no slice is needed.
- **Entry point:** `shape_job.main` writes `shape_params.csv` and `shape_params.sha256` under `--output`. Remote (S3) paths are exercised in M5b.

### Stacks (M5b and M5c)
- **Two stacks** (ADR-0003, one job per AWS service): `infra/glue` and `infra/redshift`.
- **Glue:** `glue_version = "5.1"`, G.1X, 2 workers, no VPC, no crawler, no Data Catalog; script and the two package modules in S3 (`--extra-py-files`); a role with the workload boundary that reads nothing and writes only an `m5/` prefix; a log group; a failure alarm. Run on demand.
- **Redshift Serverless is permanent**, on demand to use: idle compute costs nothing, storage is under 1 GB. It is not part of the daily state machine.
  - `base_capacity = 4` (the documented minimum; the default is 128 RPU, $52.80 an hour), `max_capacity = 8`, and a daily usage limit of 3 RPU-hours with breach action `deactivate`. A plan check pins all three.
  - **No admin login exists.** The namespace sets none of `admin_username`, `admin_user_password`, `admin_user_password_wo` or `manage_admin_password`, so there is no password in state and no Secrets Manager secret. Access is IAM only, through the Data API, which maps the caller's IAM identity to a database user and needs `redshift-serverless:GetCredentials`. A new schema needs superuser or a granted privilege, but every user may create tables in `public`, so all tables live there with an `ecp_` prefix, created by the role that loads them. Whether the namespace creator is a superuser is not documented for the API path; the first session checks it with one statement, and the design works either way.
  - **Its own network:** a small VPC with 3 private subnets in 3 Availability Zones chosen from what the account reports, a security group with no ingress, no internet gateway, no NAT and no route to the internet, no enhanced VPC routing and not publicly accessible. AWS requires two AZs without enhanced VPC routing and the Terraform provider documents three subnets in three AZs; three satisfies both. These resources are free. The Data API is called by the caller, not from this VPC, so it needs no endpoint. Redshift's documentation says that with enhanced VPC routing off "Amazon Redshift routes traffic through the internet, including traffic to other services within the AWS network", and requires a VPC path only when it is on. That `COPY` from S3 works in a VPC with no internet path is therefore an inference, proven by the first session's first statement. **Fallback, a plan change:** enhanced VPC routing on plus one free S3 gateway endpoint (ADR-0004 allows gateway endpoints).
  - **Roles** (all with the workload boundary, constants only, no wildcard with a write): one for Glue, one that Redshift uses for `COPY` from the `m5/` prefix, one for the caller of the Data API.
- **Queries (about five):** the latest curve per series, the WTI to Brent spread by tenor, contango and backwardation days, revisions per month, and one window function (a rolling percentile). The shared queries run against the local Postgres in CI where the dialects overlap; `COPY` and anything Redshift-only stay in a separate file that `sqlglot` parses, and one Redshift session confirms the results.
- **Applies** keep the M4c pattern: a stack-specific plan check, the policy gate, a saved plan, a hash approval, identity printed first, no apply from 11:45 to 12:15 Toronto, post-apply read-only checks, the plan file deleted afterwards.

### Cost (ca-central-1, AWS Pricing API, 2026-10-10)
Redshift Serverless compute $0.4125 per RPU-hour (billed per second; nothing while idle) = $1.65 an hour at 4 RPU; managed storage $0.0261 per GB-month; Glue 5.1 $0.44 per DPU-hour (2 DPU for 5 to 10 minutes = $0.07 to $0.15 a run). About $4.5 for all of M5, against the plan's $7. Every Redshift session and each batch of Glue runs needs a fresh "go".

## Consequences
- Two implementations of the shape estimate must keep agreeing; the parity test now enforces it in CI, on the full history.
- `synthetic.py` and `shape.py` re-export the moved names, so no importer changes.
- The deployed batch image does not change. `jobs/` is outside its build context, but `src/` gains two modules, so the next rebuild (not this PR) carries them; their behaviour is identical, pinned by the digest test.
- If a 4-RPU workgroup is refused in ca-central-1, 8 RPU doubles the session price; the plan check stops for a decision instead of growing silently.
- Not decided here: what M6 publishes (PLAN.md R3).
