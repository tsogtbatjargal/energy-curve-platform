# 1. Record architecture decisions

Date: 2026-10-02 · Status: accepted

## Context
Design choices in this project need a written rationale that outlives the conversation that produced them.

## Decision
Keep short ADRs in `docs/adr/`, one per decision: context, options, decision, consequences. A superseded ADR is marked and linked rather than deleted.

## Consequences
Every non-obvious choice has an answer to "why?" in the repo.
